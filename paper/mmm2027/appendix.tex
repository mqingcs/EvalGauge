\subsection{Adapter execution workflow}
For each public row, an adapter (1) compiles legal branches and its extraction, type, algebra, container, and aggregation policies; (2) selects only applicable registered relations; (3) instantiates a source witness plus valid and contract-breaking follow-ups; (4) executes the released upstream scorer and reference contract independently; and (5) stores the source identifier, expected label, raw score, exception/accounting state, compiled contract, and decision trace. Aggregation occurs only after every case-level record is materialized, so row, relation, and case views are derived from the same ledger.

The trace schema is intentionally evaluator-neutral: raw and normalized answer, parsed type and values, percent/unit/container policy, tolerance or interval branch, aggregation path, score, warnings, and rejection reason. Benchmark-specific fields remain in adapter metadata rather than entering the shared kernel.
\subsection{Reproducibility}
The release contains versioned configurations, Parquet case tables, JSON/JSONL traces, minimal failures, figures, and an HTML report. A single workflow validates the inputs, rebuilds the audit and rescoring, regenerates figures, and runs 550 fixed-seed property examples plus the regression/unit suite. Public prediction files and evaluator sources are linked to documented upstream revisions; derived tables retain stable row and response identifiers.

\subsection{Cross-benchmark probe details}
The ChartQAPro artifact retains only question/answer metadata needed by the evaluator audit; no image bytes are redistributed. Its compact table preserves the source identifiers for all 1,948 rows. Each of the 9,093 cases stores row identity, relation, expected label, official soft score, reference decision, compiled contract, and scores from both upstream implementations. The deterministic single-process probe completes in 0.92 seconds with 129 MB maximum resident memory on the audit machine. Together with MeasureBench, the artifact contains 90,871 generated decisions and 106,375 upstream comparison executions.

\subsection{Suite accounting}
The 44,566 positives and 37,212 negatives are stored one case per row with benchmark identity, relation, answer, three evaluator scores, transition, and reference trace. Natural-response tables additionally store Core-final, Physics-final, and Strict-final decisions and traces. Schema cases retain JSON and Python \texttt{repr} forms so list/tuple changes remain observable. The 2,887 source/canonical witnesses are separate.

Applicability is contract-dependent. For example, MR-09 is instantiated only for 213 temperature rows (293 branches), MR-12 for all 438 multi-interval rows (883 branch cases), and MR-23 for 80 compound-unit rows. A relation family is counted as violated only when a positive follow-up changes the official binary score relative to its canonical execution or when a verified negative is accepted. On this rule, seven positive and eight negative families violate official semantics, with no overlap, yielding the reported 15 families.

\subsection{Decision and collection traces}
The reference trace exposes extraction policy and segment, semantic type, every extracted quantity and span, matched branch, raw and canonical units, normalized value, distance to the closed interval, compiler/parser warnings, and an invalid reason. Legacy exceptions are stored as typed strings alongside the binary score. This makes the 1,534 MR-10 exceptions queryable rather than conflating them with ordinary rejections.

Published-score reproduction covers every released GPT-5 and Gemini-2.5-Pro prediction: $2\times(1{,}272+1{,}170)=4{,}884$. Contemporary transfer is join-bounded: 64 indexed files yield 949 direct-mode records, of which documented aliases link and score 637 responses across 149 rows. The other 312 are preserved in an unlinked ledger and excluded from claims.

\subsection{Extraction-policy sensitivity}
The three primary profiles feed the exact released final segment to the contract matcher. A robust-final sensitivity adds deterministic \texttt{Final Answer:} and \texttt{Reading:} indicators; it changes zero released binary scores. Whole-response sensitivity deliberately bypasses final extraction and is never presented as the replacement score. It changes 486 Gemini decisions and zero GPT-5 decisions, demonstrating response-style confounding.

\subsection{Reference-evaluator checks}
Tests cover Decimal and clock round trips, unit conversion, schema/alternative permutation, released and extended final-answer extraction, LaTeX unit wrappers, numeric-string separation, token boundaries, contradictory or non-finite values, mixed fractions, and known failure classes. Direct comparison with upstream behavior covers 88,189 executions. These checks establish reproducibility and generated-suite closure.

The companion artifact includes executable source, all 90,871 generated case-level decisions, released- and contemporary-output traces, the 35-transition taxonomy and manual inspection record, version metadata, a browsable HTML audit, and one-command rebuilds. Three MeasureBench thumbnails used only in Fig.~\ref{fig:teaser} are retained with their source row identifiers; no ChartQAPro image column is redistributed.
